数据库 u.db、上传的图片视频、自动备份都放在这个目录里。改完需要重启服务器才生效（不会搬迁旧数据，请先把旧目录里的 u.db 与 media 拷到新目录，或用「恢复数据」）。修改会记进「修改记录」。

人机频率

每 N 秒生成 M 条，条数 0 表示关闭

七类动作各自按「每 N 秒做 M 条」运行：N 填 1-3600 秒，M 填 0-1000 条，M 为 0 表示关掉这一类。实际间隔会在 ±35% 内随机抖动，看起来不像定时脚本。人机私信会随机发给最近活跃的真实用户，人机关注优先挑真人账号，没有合适对象时自动跳过这一轮。

未启动
手机/电脑浏览器第一次打开不会直接进后台，而是先看到 serveo 的「Browser Warning」警告页——点页面上的 Continue 就好（只出现一次）。想跳过这一步，用上面「手机打开后台」那个链接，它带了跳过参数。
serveo 的地址在隧道运行期间固定不变（服务器重启后才会换）。想让地址永久固定：先 注册本机公钥 （用 Google / GitHub 登录，一条命令即可），再在上面的「固定子域」里填个名字。 

        
隧道进程由服务器自己拉起（ssh -R 80:127.0.0.1:端口 …@localhost.run），关掉服务器窗口会一起退出。免费地址会周期性更换，换完点「刷新」看新地址；要长期固定域名，把「自定义命令」改成 cloudflared / ngrok 之类即可。
