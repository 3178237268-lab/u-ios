数据目录（上传目录）

数据库 u.db、上传的图片视频、自动备份都放在这个目录里。改完需要重启服务器才生效（不会搬迁旧数据，请先把旧目录里的 u.db 与 media 拷到新目录，或用「恢复数据」）。修改会记进「修改记录」。
优先级：环境变量 U_DATA_DIR > 配置文件 data-dir.json > 默认 server/data。

App 与服务器同时生效

超出上限的上传会被服务器直接拒绝；App 内选择文件时也会按这里的数值提前提示。

人机频率

每 N 秒生成 M 条，条数 0 表示关闭

四类动作各自按「每 N 秒发 M 条」运行：N 填 1-3600 秒，M 填 0-1000 条，M 为 0 表示关掉这一类。服务器同时把设置换算成每秒速率下发，老版本 App 照旧工作。人机私信会随机发给最近活跃的真实用户，没有可发对象时自动跳过这一轮。
